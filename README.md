# toringkpa2
TORING (Tools of Reporting and Monitoring KPA II) merupakan aplikasi berbasis web yang digunakan untuk mendukung pelaporan dan monitoring pelaksanaan anggaran di lingkungan Konsolidasi Pelaksanaan Anggaran II, Direktorat Pelaksanaan Anggaran, DJPb.

## Modul Monitoring Penyesuaian IKPA & Master Exception
Menu **Monitoring Penyesuaian IKPA** (`monitoring-ikpa.html`, kode di `ikpa-adj/`). Dokumentasi, skema database, kunci deduplikasi, cara uji, dan langkah aktivasi Firebase: [`docs/MODUL_IKPA_ADJ.md`](docs/MODUL_IKPA_ADJ.md).
