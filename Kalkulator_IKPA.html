Kalkulator Nilai IKU IKPA BUN

Kalkulator IKPA

Menghitung 7 indikator Kinerja Pelaksanaan Anggaran dan Nilai IKPA komposit untuk triwulan pilihan Anda, sekaligus di tiga level agregasi — K3 PA, K4 PA, dan K4 Kanwil — langsung dari file sumber yang Anda unggah.

Seluruh perhitungan berjalan di peramban Anda sendiri — file yang diunggah tidak dikirim atau disimpan di server mana pun. Unggah kembali file sumber dan file referensi setiap kali menjalankan perhitungan.
Periode Perhitungan Berlaku untuk seluruh indikator dan Nilai IKPA. Mengganti triwulan akan mengosongkan hasil yang sudah dihitung di sesi ini.

Kalkulator ini mereplikasi metodologi yang sudah diverifikasi pada berkas Excel formula-driven untuk setiap indikator, termasuk agregasi K4 Kanwil yang sudah dipakai sebelumnya. Hasil di sini bersifat ringkasan (Rekap per level) — untuk audit trail lengkap per Satker, gunakan berkas Excel masing-masing indikator.
